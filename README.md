## STORS 首页优化预览

双击 `index.html` 用浏览器打开即可查看（需联网，首屏插画仍从线上站点加载）。

### 改动内容
1. 配色点缀：在原灰蓝基调上增加蓝 #2F6FD6、青 #12A594、橙 #E89A2C、珊瑚 #E3644A 四个点缀色，用于 Hero 标题渐变与标签、产品卡顶部色条、流程序号、编号、FAQ 展开条、页脚顶部渐变线、按钮。
2. 场景图（不含任何服务器/显卡产品）：城市夜景横幅（Solutions 与 Process 之间）、流程区会议沟通图、维修区两张工作场景图、"What we cover" 港口物流图、联系区沟通图。
3. 新增办公环境模块 `#office`（About 之后），导航新增 Office 入口：接待区、办公区、会议室、工位四张图 + 到访信息卡 + 四项到访服务说明。

### 文件
- `assets/enhance.css`：全部新增样式，叠加在原站 CSS 之后，不改原有样式文件。
- `assets/img/`：新增图片，已压缩。
- `index.html`：基于线上页面生成的静态预览，语言切换、表单提交等交互在预览中不可用。
